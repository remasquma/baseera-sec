# بصيرة للأمن السيبراني | Baseera Sec

أداة تجريبية محلية لفحص تطبيقات الويب والحزم البرمجية وتوثيق النتائج. لا تضمن
الأداة كشف جميع الثغرات، أو انعدام الإنذارات الكاذبة، ولا تُعد شهادة امتثال أو
بديلًا عن اختبار أمني مستقل. يستلهم سير العمل بعض المفاهيم من PTES وNIST SP
800-115 دون ادعاء تنفيذ المنهجيتين بالكامل.

## القدرات الحالية

- فحوصات نشطة محددة لـSQL injection وReflected XSS وSSTI وCommand Injection
  وPath Traversal وSSRF وبعض إعدادات HTTP. التغطية تعتمد على اكتشاف المسارات
  والمدخلات، وقد تفوت حالات صحيحة.
- تحليل محلي ساكن لبعض ملفات المصدر والإعدادات، بما في ذلك أنماط بيانات
  الاعتماد، ومؤشر Shannon entropy للقيم المرشحة. لا تُعرض قيمة السر في دليل
  النتيجة.
- فحص IDOR المؤكد اختياري ويتطلب حسابين مستقلين وموردي تحكم مختلفين على الأصل
  نفسه؛ اختلاف رمز HTTP أو محتوى الاستجابة وحده ليس إثباتًا.
- زحف اختياري بواسطة Chrome/Chromium عند توفره. لا يضمن تغطية تطبيقات SPA.
- رفع حزم محدودة الحجم، وتصدير التقارير JSON وHTML وTXT وSARIF؛ PDF متاح عند
  توفر Chromium. لم يُثبت توافق كل ملف SARIF مع المنتجات الخارجية.
- لا يستخدم التطبيق خدمة ذكاء اصطناعي سحابية. تُعرض مخرجات النماذج المحلية
  الخام لأغراض التشخيص فقط؛ لا تُعتمد لتصنيف آمن/خبيث لغياب خرائط فئات موثوقة
  ومعايرة مستقلة. نتائج القواعد منفصلة عن الاستدلال العصبي.
- بيانات EPSS أو درجات الامتثال لا تُختلق عند غيابها، وتظهر الضوابط غير
  المختبرة على أنها غير مختبرة بدل احتسابها ناجحة.

## تشغيل محلي

المتطلبات الأساسية: Python 3.10+؛ وChrome/Chromium اختياري للزحف وPDF.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:8765`. التطبيق وAPI غير محميين بمصادقة مستخدم، ويجب
تشغيلهما محليًا فقط. يرفض التطبيق اتصالات العملاء غير المحلية وطلبات التغيير
عبر المواقع، كما أن خادم التشغيل الافتراضي مربوط بـ`127.0.0.1`. لا تستخدم
`--host 0.0.0.0` أو reverse proxy أو port forwarding. العمليات المحلية الأخرى
على الجهاز تظل قادرة على الوصول إلى API. خيار فحص العناوين الخاصة معطل افتراضيًا
ولا ينبغي تفعيله إلا لهدف تملكه.

## مجموعة الاختبار

المجلد `benchmark/` يحتوي على **Baseera Sec Synthetic Verification Benchmark
Testbed**، وهي مجموعة داخلية من 34 حالة وليست OWASP Benchmark الرسمي. القياسات
تصف هذه الحالات الاصطناعية فقط ولا تثبت الأداء على أهداف حقيقية. راجع
[منهجية الاختبار](./docs/BENCHMARK_METHODOLOGY.md) و
[تقرير تدقيق النماذج](./docs/LOCAL_MODEL_AUDIT.md).

## مجموعة النماذج المحلية

توجد ملفات CodeBERT وDistilRoBERTa وLightGBM تحت
`core/ai/models/Nazzoor_Models/`. الأوزان الحالية خالية من NaN/Inf في القياس
المتاح، لكن خرائط الفئات ومصدر التدريب غير موثقين، كما أن LightGBM محجوب بسبب
عدم توافق إصدار scikit-learn. لا تُفسر الفئة العددية أو softmax كاحتمال أمني
موثوق. التفاصيل في [LOCAL_MODEL_AUDIT.md](./docs/LOCAL_MODEL_AUDIT.md).
